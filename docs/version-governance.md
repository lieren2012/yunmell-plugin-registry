# 版本对应与发布治理

## 三个版本层次

1. **官方版本**：上游插件包或官方仓库的版本、来源和固定 commit。
2. **云迈适配版本**：云迈为权限、租户、配置、事件或 UI 做的适配层版本。
3. **插件中心状态**：该组合是否可以在云迈插件中心展示、安装和升级。

云迈适配版本变化，不代表官方插件版本变化；官方插件升级，也不能自动视为云迈兼容。

## 状态定义

- `draft`：条目已登记，尚未进入测试。
- `testing`：完成构建，正在做功能、权限、兼容性或许可证复核。
- `published`：允许插件中心展示并提供给满足条件的租户安装。
- `deprecated`：仍可运行，但不再接受新的生产安装，需迁移到替代版本。
- `blocked`：存在安全、许可证、兼容性或供应链问题，禁止展示和安装。

## Pull Request 必查项

- 官方来源和版本可追溯；
- 云迈适配层版本与最低 Agent OS/桌面版本明确；
- 许可证、第三方依赖和发布限制已经记录；
- 产物 URL、SHA-256 和平台信息齐全；
- 权限、租户隔离、审计和失败关闭策略已验证；
- 变更不会覆盖已有条目的历史关系。

插件中心只读取 `published` 条目。`testing` 条目可以用于内部环境，但不能作为生产安装源。
